## Purpose and Organization:
This folder is intended to contain the computer vision exercise code for assignment number one and necessary files for running
that code. It is organized with each exercise abbreviated as E1 or E2 for exercise 1 or exercise 2, followed by the name of
the author of that specific file. additional files can be found at the bottom of the folder, such as datafile.txt
which is necessary to run exercise 1. Exercise 1 is an introduction to working with numpy to handle computatations
making use of arrays, matrix math, sorting arrays, finding maximum and minimum value, finding counts of values, as well
as printing. In exercise 2 we were asked to design and implement a finite state machine, inputting a character string from 
the user, and checking to see if the characters 'abcd' appear in that order in the inputted string, resetting back to previous 
characters if it is not present.
