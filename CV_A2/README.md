## Programs

### `arduino_1a.ino`

### `2a.py`
This program takes continuous pictures with the camera and scans for ArUco Markers and displays the ID onto the LCD screen

### `python_1b.py`
Sends a number to the Arduino from the pi then receives the same number summed with 100 back and displays it on the Pi

Receives a number from the Pi and adds 100 to it and then sends the new number to the Raspberry Pi
